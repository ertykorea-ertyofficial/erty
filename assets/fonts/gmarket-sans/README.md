Gmarket Sans font assets for the ERTY project.

Included files:
- `GmarketSansLight.otf` - weight `300`
- `GmarketSansMedium.otf` - weight `500`
- `GmarketSansBold.otf` - weight `700`

Usage:
- Global `@font-face` is declared in [global.css](/C:/Users/ERTY%20OFFICIAL%20PROJECT/assets/css/global.css)
- CSS variable: `--font-korean-display`
- CSS variable: `--font-korean-brand`
- Utility class: `.font-gmarket-sans`
- Utility class: `.font-gmarket-sans-brand`

Notes:
- Only the actual OTF files were copied into this folder.
- `__MACOSX` metadata and `.DS_Store` files from the source bundle were intentionally excluded.
- This folder is the project-local authoritative copy for the current workspace.
