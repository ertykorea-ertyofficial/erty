# ERTY CTA Source

## 목적

이 문서는 제품 상세페이지 이미지에서 직접 확인한 CTA 관련 문구와 전환 신호를 정리한 문서다.
`ertyofficial.com`에서 `ertyofficial.shop`으로 연결할 CTA 설계의 source note로 사용한다.

## 소스 기준

- 기준 소스: `private/product-detail-pages`
- 직접 구매 버튼형 CTA는 이미지셋 전반에서 거의 확인되지 않았다
- 아래 문서는 `명시적 source 문구`와 `레이아웃 기반 추론`을 분리해서 정리한다

## 3. 명시적 구매 CTA 부재에 대한 판단

- `구매하기`, `장바구니`, `스토어 바로가기`처럼 직접 구매를 지시하는 문구는 이번 이미지셋에서 확인되지 않았다.
- 상세페이지는 전환보다 설명, 성분, 후기, 사용법, 정품 신뢰 구축 비중이 높다.
- 따라서 메인 도메인에서는 source 문구를 그대로 복사하는 방식보다, 상세페이지가 이미 축적해 둔 신뢰 신호 뒤에 `ertyofficial.shop` 전환 버튼을 배치하는 방식이 맞다.

## 4. 재사용 가능한 CTA 소스 문구

다음 문구는 source-visible이므로 메인 도메인에서 톤 변형 없이 참고할 수 있다.

- `구매 전 꼭 확인해 주세요`
- `Real Review`
- `FAQ`
- `이렇게 사용하세요!`
- `이런 분들께 추천합니다.`
- `ERTY's Suggestion`

## 6. CTA 설계 메모

- 메인 도메인에서는 hard sell보다 `공식`, `정품`, `루틴`, `사용법`, `후기`를 먼저 제시한 뒤 구매 CTA를 배치하는 것이 source와 맞는다.
- cleanser / toner / sun cream 계열은 사용법 안내 뒤 CTA가 자연스럽다.
- ampoule / cream / kit 계열은 전후 / 후기 / 추천조합 뒤 CTA가 더 강하다.
- 링크 목적지 URL은 source 이미지에 없으므로, 실제 구현에서는 `ertyofficial.shop`의 제품 상세 URL을 별도 매핑해야 한다.

## 7. 오픈 체크

- `37 Intensive Cellular ER Cream` 일부 컷에 버튼형 문구가 더 있을 가능성은 있으나, 이번 통합 문서에서는 직접 재확인된 문구만 확정 항목으로 넣었다.
- CTA URL 매핑은 소스 이미지가 아니라 쇼핑 도메인 실제 상품 경로 확인 후 별도 확정해야 한다.
