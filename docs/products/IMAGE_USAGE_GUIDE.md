# ERTY Image Usage Guide

## 목적

이 문서는 전제품 누끼컷을 실제 디자인 시스템과 제품 카드 / 상세 레이아웃에 어떻게 배치할지 정리한 사용 가이드다.
기준 원본은 `private/product-cutouts`이며, 패키지 표기와 넘버링 체계를 보존하는 방향으로만 사용한다.

## 기본 원칙

1. 제품 이미지는 단순 장식이 아니라 제품 번호 체계와 라인 정체성을 전달하는 주 시각 장치다.
2. 카드와 상세 모두 숫자, 로고, 제품 타입 표기가 잘리지 않도록 원본 비율을 최대한 유지한다.
3. 모든 제품에 같은 클래스의 이미지를 쓰는 것을 우선한다. 카드에서는 가능하면 `Product Only`만 사용한다.
4. 박스 이미지는 보조 정보용으로 쓰고, 본품과 경쟁하는 주 이미지로 남발하지 않는다.
5. 자산이 적은 제품은 컷 수를 억지로 늘리지 않고, 타이포 / 성분 / 근거 블록으로 시각 밀도를 보완한다.

## 이미지 우선순위

### 1순위

- `Product Only`
- 제품 카드, 제품 허브, 비교표, 추천 섹션 기본값

### 2순위

- `Combo`
- 상세 Hero, 첫 인상 비주얼

### 3순위

- `Box Only`
- 패키지 정보 보조, 용량 비교, variant browsing

### 4순위

- `Set / Unit`
- 앰플, 세트 구성, 구성품 안내

## 카드 설계 규칙

### 대표 자산 선택

1. 한 제품당 카드 대표 컷은 1개만 고정한다.
2. 사이즈가 여러 개인 경우 카드 기준 SKU를 정해 일관되게 사용한다.
3. 대표 컷은 가능한 한 본품만 있는 투명 PNG를 사용한다.
4. box와 product를 경쟁적으로 같이 올리는 카드는 예외 상황에서만 사용한다.

### 프레임과 비율

1. 기본 카드 프레임은 세로형 cutout을 수용하는 portrait-friendly 비율로 잡는다.
2. `cover`보다 `contain`을 우선한다.
3. tube / bottle 제품에 정사각 강제 crop을 적용하지 않는다.
4. cap, neck, base, tray edge가 잘리지 않도록 상하 여백을 확보한다.

### 카드별 예외

- `[1]`, `[3]`: product-only가 곧 authoritative image다.
- `[2]`: set 구성이 복잡하므로 카드에서는 `5pcs ... _제품`처럼 가장 단순한 대표 컷을 쓴다.
- `[50]`: `박스+제품`은 카드 기본값이 아니라 상세 Hero 예외 컷이다.
- `[57]`: 카드에서는 front-facing 컷 하나만 고정하고 angled cut은 상세용으로 남긴다.

## 상세 레이아웃 규칙

### Hero 섹션

1. 가장 먼저 보여줄 컷은 `Combo`를 우선한다.
2. `Combo`가 없으면 `Product Only + Box Only`를 병렬 조합한다.
3. 상세 Hero에서는 제품 번호가 첫 인상에서 바로 읽혀야 한다.

### 중간 섹션

1. 메커니즘 / 성분 / 사용 맥락 설명에는 본품 단독 컷을 우선한다.
2. 용량 차이가 중요한 제품은 작은 사이즈와 큰 사이즈를 같은 섹션에서 비교 배치한다.
3. 앰플, 세트형 제품은 `Set / Unit` 컷을 별도 구성 설명 섹션에서만 쓴다.

### 하단 섹션

1. 패키지 디테일이나 보관 / 구성 설명에는 `Box Only`를 보조적으로 사용할 수 있다.
2. CTA 직전에는 대표 본품 컷이나 Hero 대표 컷을 다시 사용해 인지 연속성을 만든다.

## 제품 패키지 표기 반영 기준

### 제품 번호

1. 숫자는 장식이 아니라 제품 식별 체계다.
2. 카드 타이틀, 상세 H1, 비교표 라벨에서 제품 번호를 이름보다 먼저 혹은 함께 노출한다.
3. 동일 라인 제품을 묶을 때 첫 자리 수를 시각 분류 축으로 활용한다.

### 제품 타입

1. 두 번째 자리 수는 cleanser / toner / booster / cream 같은 제품 타입 해석에 연결한다.
2. 타입이 다른 제품을 한 섹션에 섞을 때는 숫자와 타입명이 동시에 보이도록 한다.

### 용량 표기

1. 용량이 복수인 제품은 대표 용량을 기본 카드에 고정한다.
2. 상세 페이지에서는 작은 용량과 큰 용량을 같은 문맥에서 비교하되, 실제 제공 컷이 있는 경우에만 병치한다.

## 이미지 배치 기준

### 허용

- 세로 중심 정렬
- 투명 배경 유지
- 원본 비율 유지
- 라인 컬러를 반영한 약한 배경 보조
- 박스와 본품의 병렬 배치
- 각도 컷을 상세 서브 갤러리에 한정 사용

### 지양

- 숫자 타이포 절단
- 로고 절단
- 제품 실루엣이 휘거나 늘어나는 리사이즈
- 서로 다른 자산 클래스를 카드 그리드 안에서 혼용
- 단독 컷이 있는데 박스 컷만 쓰는 카드 설계

## 제품군별 레이아웃 템플릿 제안

### 클렌저 / 토너

- 대상: `11`, `13`, `21`, `23`
- 카드: 본품 단독
- 상세: 본품 + 박스 + 용량 비교

### 부스터

- 대상: `15`, `25`, `35`, `55`
- 카드: 30ml 본품 단독
- 상세: 100ml 본품 + 박스 중심
- 공통 템플릿 공유 가능

### 크림

- 대상: `27`, `37`, `57`
- 카드: 본품 단독
- 상세: 본품 중심 Hero + 박스 보조

### 세트 / 특수 제형

- 대상: `2`, `3`, `50`
- `[2]`: set / unit 컷을 상세 중간 구성 설명용으로 분리
- `[3]`: 단일 대표 컷 재사용 전제
- `[50]`: `박스+제품` 컷을 상세 Hero 기본값으로 사용

## 운영 메모

1. 디자인 시스템에서 이미지 슬롯은 `card-primary`, `detail-hero`, `detail-support`, `detail-package`, `detail-set`처럼 역할 기준으로 정의한다.
2. 제품별 대표 컷이 정해지면 구현 단계에서 파일명을 별도 manifest로 고정하는 것이 좋다.
3. 원본 자산이 추가되면 이 문서와 `VISUAL_ASSET_MAP.md`를 먼저 갱신한 뒤 레이아웃에 반영한다.
