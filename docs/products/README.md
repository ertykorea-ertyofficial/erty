# ERTY Product Documents

## 목적

이 경로는 ERTY 제품 정의 문서의 기준 인덱스다.
제품별 정의 문서와 메커니즘 / claim 가이드의 authoritative local path를 안내한다.

## 현재 기준 원본

현재 작업 기준 원본은 사용자가 전달한 한국어 마크다운 패키지다.
이 패키지는 프로젝트 내부 `private/product-docs/korean`에 보관한다.

추가 검증용 원본으로 제품별 기술 소개서 PDF를 `private/product-docs/technical-pdf`에 보관한다.
제품 카드 / 상세 레이아웃 설계용 누끼컷 원본은 `private/product-cutouts`에 보관한다.
링크형 자료 재검증용 PDF 번들은 `private/source-pdf-review/markdown-pdf-version`에 보관한다.

## 사용 원칙

1. 제품 설명과 카피 작성은 한국어 마크다운 패키지를 우선 기준으로 본다.
2. 제품 간 공통 원리는 tracked 문서 `PRODUCT_MECHANISM.md`를 우선 기준으로 본다.
3. 제품 claim 표현과 금지 표현은 tracked 문서 `PRODUCT_CLAIM_RULE.md`를 우선 기준으로 본다.
4. 제품별 기술 소개서 PDF와 PDF review bundle은 검증용 원본 레이어로 함께 본다.
5. PDF와 마크다운 사이에 차이가 생기면 PDF를 근거로 재검토하되, 변경 이력은 문서화한다.
