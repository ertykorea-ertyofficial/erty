# ERTY Evidence Source

## 목적

이 문서는 제품 상세페이지 이미지에서 확인한 근거 요소를 제품별로 분리 정리한 문서다.
Evidence 페이지, proof block, FAQ 검증, claim 검수의 1차 source note로 사용한다.

## 판독 원칙

- `이미지에서 직접 보이는 항목`만 기록한다
- 후기형 자료와 임상형 자료를 섞지 않는다
- 수치가 보여도 측정 항목과 시험 조건이 명확하지 않으면 `추가 검증 필요`로 표기한다

## 공통 면책 / 신뢰 문구

- 전 제품 다수에 상단 저작권 / 공식판매처 안내가 반복된다
- `hidden tag` 정품 인증 확인 안내가 반복된다
- 일부 성분 / 효능 패널에는 `원료적 특성에 한함` 문구가 보인다

## Evidence 작성 시 주의

1. 후기 / 리뷰 / 만족도 수치를 임상 수치로 단정하지 않는다
2. 퍼센트 값은 항목명, 기간, 대상, 측정 조건을 기술서 PDF와 교차검토한 뒤에만 claim으로 승격한다
3. 패키지컷과 성분 카드는 `설명 근거`로, 전후 이미지와 그래프는 `결과 근거 후보`로 분리해 다룬다
