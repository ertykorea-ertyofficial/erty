# ERTY Brand Source Map

## 목적

이 문서는 사용자가 전달한 원본 브랜드 자산의 authoritative local path를 고정한다.
원본 파일은 프로젝트 내부에 보관하되 GitHub에는 올리지 않는다.

## 원본 자산 보관 경로

- 로고 원본: `private/brand-source/logo`
- 브랜드 스토리 및 제품 넘버링 원본: `private/brand-source/story-numbering`
- 국가별 전제품 소개서 원본: `private/brand-source/product-brochures`
- 링크 재검증용 PDF 번들: `private/source-pdf-review/markdown-pdf-version`

## 현재 보관 완료 자산

### 로고

- 총 6개 파일 보관 완료
- 주요 파일 예시:
  - `erty logo_black.png`
  - `erty logo_white.png`
  - `erty logo no slogan_black.png`
  - `erty logo no slogan_white.png`
  - `erty logo-02.png`
  - `erty logo-02.jpg`

### 브랜드 스토리 / 제품 넘버링

- 총 3개 파일 보관 완료
- 포함 파일:
  - `에르띠-브랜드 스토리.png`
  - `에르띠-브랜드 아이덴티티 제품 넘버링.png`
  - `에르띠-제품 넘버링가이드.png`

### 국가별 전제품 소개서

- 총 5개 PDF 보관 완료
- 포함 언어:
  - 한국어
  - 영어
  - 일본어
  - 중국어
  - 베트남어

## 운영 원칙

1. 원본 자산의 authoritative path는 `private/brand-source` 하나로 유지한다.
2. 원본 자산은 비공개 로컬 보관 기준으로 관리하고 GitHub에 올리지 않는다.
3. 실제 웹에 반영할 공개용 자산은 검토 후 별도 경로로 파생본을 만든다.
4. 링크나 채팅 기반 원문을 재검증한 PDF 번들은 `private/source-pdf-review/markdown-pdf-version`에 보관한다.
5. 페이지 설계와 카피 작업은 `docs/brand/*.md`와 이 원본 자산 경로를 함께 기준으로 본다.
