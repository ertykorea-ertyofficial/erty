# ERTY Brand Language Rule

## 문서 목적

이 문서는 ERTY 브랜드 문체, 핵심 어휘, 명명 규칙, 금지 표현을 고정한다.

## 소스

- 원문 PDF: `private/source-pdf-review/markdown-pdf-version/BRAND_LANGUAGE_RULE.md (한국어 버전).pdf`
- 보조 원본: `private/brand-source/story-numbering`

## 톤앤매너

- 단정적이고 규정적이어야 한다
- 설명보다 선언문처럼 명확해야 한다
- 전문적이되 접근 가능한 표현을 사용해야 한다
- 즉각성과 결과를 분명히 드러내야 한다
- 과장된 감성 문구보다 목적 지향적이고 임상적인 어조를 우선한다
- 스킨케어를 재정의하고 구조와 결과를 강조하는 언어를 사용한다

## 핵심 어휘

- 즉각적인 피부개선
- 아름다움을 동시에
- 더마 코스메틱 K-뷰티 브랜드
- 문제성 피부
- 즉각적인 개선을 원하는 고객
- 전문 에스테틱 브랜드
- 효과적이고 즉각적인 기능
- emergency room + beauty
- 특허성분과 유효성분
- 지속적인 연구와 개발

## 제품 명명 규칙

- 제품 번호와 기능 라인을 함께 표기한다
- 예시: `11 밸런싱 클렌징젤`
- 각 제품 번호는 기능 라인과 사용 순서를 함께 나타낸다
- 프로페셔널 키트는 단계명을 명확히 표기한다
- 예시: `Step 1 - 수딩 솔루션`

## 기능 라인 표현

- 밸런싱: 진정
- 하이드레이팅: 수분
- 리바이탈라이징: 재생
- 브라이트닝: 미백
- 프로페셔널 라인: 토닝 트리트먼트 키트

## 피해야 할 표현

- 피부에 좋다
- 흡수력이 좋다
- 막연하고 추상적인 효능 표현
- 과도하게 감성적인 문구
- 근거 없이 넓게 퍼진 미사여구
- 설명 없이 즉효를 단정하는 표현

## 문장 작성 원칙

1. 어떤 문제를 해결하는지 먼저 말한다.
2. 즉각성 또는 기능적 변화를 분명히 적는다.
3. 제품 / 브랜드 / 기능 라인을 섞지 않고 층위를 구분한다.
4. 반복해야 하는 핵심 문구는 일관되게 유지한다.

## 반복 강화가 필요한 브랜드 문구

- 즉각적인 피부개선과 아름다움
- 더마 코스메틱 K-뷰티 브랜드
- emergency room + beauty

## 현재 해석 메모

- 메인 도메인 카피는 전반적으로 짧고 강한 선언형 문장 구조가 맞다.
- 구체적 문제와 기능이 없는 추상 문장은 최대한 줄여야 한다.
- 브랜드 언어는 마케팅 과장보다 구조적이고 결과 지향적인 쪽으로 유지해야 한다.
- 제품 번호와 기능 라인은 브랜드 언어의 일부이므로 카피와 UI 모두에서 함께 읽혀야 한다.
