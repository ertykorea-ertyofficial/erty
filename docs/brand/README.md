# ERTY Brand Documents

## 목적

이 경로는 ERTY 브랜드 기준 문서를 보관하는 authoritative path다.
사용자가 전달한 브랜드 데이터와 이후 추가되는 브랜드 자산 문서는 이 경로를 기준으로 정리한다.

## 현재 수집 완료 문서

- `BRAND_CORE.md`
- `BRAND_LANGUAGE_RULE.md`
- `BRAND_POSITIONING.md`
- `BRAND_SOURCE_MAP.md`

## 현재 수집 완료 원본 자산

- 로고 원본 6개 파일
- 브랜드 스토리 / 제품 넘버링 원본 3개 파일
- 국가별 전제품 소개서 PDF 5개 파일

원본 자산의 authoritative local path:

- `private/brand-source/logo`
- `private/brand-source/story-numbering`
- `private/brand-source/product-brochures`
- `private/source-pdf-review/markdown-pdf-version`

원본 자산은 로컬 보관 전용이며 GitHub에 올리지 않는다.

## 아직 미수집 문서 / 자산

- 브랜드 무드보드
- 추가 제품 상세 원본 자료

## 사용 원칙

1. 브랜드 정의는 `BRAND_CORE.md`를 우선 기준으로 본다.
2. 문체와 카피 규칙은 `BRAND_LANGUAGE_RULE.md`를 우선 기준으로 본다.
3. 시장 맥락과 차별점은 `BRAND_POSITIONING.md`를 우선 기준으로 본다.
4. 원본 자산 위치와 보관 원칙은 `BRAND_SOURCE_MAP.md`를 기준으로 본다.
5. 홈페이지 설계와 카피는 위 문서들을 먼저 읽고 시작한다.

## 소스

현재 authoritative source는 프로젝트 내부 로컬 원본이다.

- `private/source-pdf-review/markdown-pdf-version/BRAND_CORE.md (한국어 버전).pdf`
- `private/source-pdf-review/markdown-pdf-version/BRAND_LANGUAGE_RULE.md (한국어 버전).pdf`
- `private/source-pdf-review/markdown-pdf-version/BRAND_POSITIONING.md (한국어 버전).pdf`
