# 06_MULTILINGUAL_GLOSSARY

## 목적

이 문서는 한국어 canonical source와 영어 reference term을 정리한 multilingual glossary다.
정확한 용어 통일과 SEO/GEO 확장을 위한 기반으로 사용한다.

## source basis

- `docs/brand/BRAND_LANGUAGE_RULE.md`
- `docs/brand/BRAND_POSITIONING.md`
- `private/product-docs/korean/products/*.md`

## language policy

1. 한국어가 canonical source다.
2. 영어는 reference translation이다.
3. locale route가 구현되기 전까지는 영어 용어를 metadata / glossary / internal reference 수준으로만 사용한다.

## translation cautions

1. 번호 체계는 번역하지 않는다.
2. 브랜드 핵심 문구는 의미를 넓히지 않는다.
3. 문제 해결 표현은 규정된 claim rule 안에서만 번역한다.
